Wireshark DNS Query Inspection Lab

This guide explains how to isolate and analyze a specific Domain Name System (DNS) query packet to view its structural properties and transaction details.

Objectives
* Identify an outbound DNS request within filtered traffic.
* Inspect Layer 2 through Layer 4 packet data.
* Extract structural fields from the DNS query protocol layer.

Step-by-Step Instructions

1. Locate a DNS Query Packet
   Filter the packet capture using the `dns` keyword.
   Scan the **Info** column for outbound requests starting with `Standard query`.
   Click on a query row (e.g., Packet **202**) to highlight it.

2. Access Packet Details
   Move down to the **Packet Details Pane** (middle section of the screen) to view the layer-by-layer breakdown.

3. Expand Protocol Sections
   Click the arrow icons to expand the relevant transport and application headers.
   Specifically expand the **Domain Name System (query)** block at the bottom of the list.
