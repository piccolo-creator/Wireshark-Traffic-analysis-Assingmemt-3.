 Examining an HTTP GET Request

This guide shows you how I picked an HTTP GET request in Wireshark and look inside it to see the headers and the website domain name your browser is requesting.

What I Will Do
* Select an outbound web request from your filtered list.
* Expand the application layer protocol to view plain-text browser parameters.

 Steps

1. Find the GET Request
   * Make sure your traffic display is filtered using the `http` keyword.
   * Look down the Info column for an outbound request that starts with `GET`.
   * Click on that row to select it.

2. Open the Protocol Details
   * Look at the middle box on your screen.
   * Click the small arrow next to Hypertext Transfer Protocol at the bottom to open it up.

 What the Image Shows

If you look at the selected packet, you can read the unencrypted browser details:

* The Request Command: `GET / HTTP/1.1\r\n` (The browser is asking for the main home page using HTTP version 1.1).
* The Target Website: `Host: example.com\r\n` (This confirms the destination web address).
* The Web Browser (User-Agent): `Mozilla/5.0 (X11; Linux x86_64; rv:140.0) Gecko/20100101 Firefox/140.0\r\n` (This shows the request came from a Firefox browser running on Linux).
* Language settings: `Accept-Language: en-US,en;q=0.5\r\n` (Tells the server the user prefers US English).
* The Full Target URL: `[Full request URI: http://example.com]` (The final reconstructed address path generated by Wireshark).
